# Constitución — MYF Construcciones

1. **Propósito:** landing profesional para presentar servicios y facilitar consultas.
2. **Visual:** azul marino, blanco y dorado; estilo premium, claro y confiable.
3. **Contenido:** hero, servicios (gasfitería, construcción/remodelación, electricidad), beneficios, galería, contacto y testimonios solo reales.
4. **Stack:** React + Vite; GitHub Pages; sin backend por defecto.
5. **Veracidad:** no inventar contactos, cobertura, precios, certificaciones, garantías, reseñas ni experiencia. Datos pendientes deben quedar como placeholders y no publicarse.
6. **Accesibilidad:** HTML semántico, teclado, foco visible, contraste, alt y `prefers-reduced-motion`.
7. **Calidad:** imágenes optimizadas, SEO básico, dependencias mínimas y build verificable.
8. **SDD:** especificar, aclarar, planificar, dividir tareas, implementar incrementalmente y revisar.
9. **Publicación:** configurar `base` según el repo y no publicar/push sin autorización expresa.
