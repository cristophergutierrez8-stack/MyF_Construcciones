---
name: github-pages-deployment
description: Despliegue Vite a GitHub Pages.
---
Confirma el nombre del repo. Configura `base` según la subruta. Usa workflow de GitHub Actions para build y publicar `dist/`. Verifica recursos y rutas. No incluyas secretos. No hagas push ni actives publicación sin autorización. Confirma URL real antes de decir que está publicado.
