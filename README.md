# MYF Construcciones — OpenCode + SDD

Configuración personalizada para construir la landing page aprobada visualmente: azul marino, blanco y dorado; hero con CTA de cotización; servicios; beneficios; galería; contacto; testimonios únicamente reales.

## Incluye
- 7 agentes: coordinator, planner, implementer, reviewer, frontend-design, testing y seo-reviewer.
- 8 comandos SDD/feature.
- 4 skills.
- AGENTS.md, MEMORY.md, docs/constitution.md y especificación inicial.

## Instalación
1. Descomprime el ZIP.
2. Haz copia de seguridad del proyecto.
3. Copia el contenido en la raíz del proyecto MYF Construcciones, conservando `.opencode/`, `docs/` y `specs/`.
4. Si ya existen archivos con el mismo nombre, compáralos antes de reemplazarlos.
5. Abre la raíz del proyecto en OpenCode y pide al coordinador una inspección sin cambios.
6. Revisa y aprueba `specs/001-landing-myf/spec.md` antes de planificar e implementar.

## Importante
La maqueta es una referencia visual. Teléfonos, testimonios, dirección y otros datos que aparezcan en imágenes son ilustrativos y no deben publicarse como reales. Este ZIP configura instrucciones; no contiene la web terminada ni se ha probado todavía en tu instalación local.
