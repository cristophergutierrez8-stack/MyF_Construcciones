# Instrucciones generales — MYF Construcciones

## Objetivo y diseño
Crear una landing page comercial para MYF Construcciones: gasfitería, construcción/remodelación y electricidad. Dirección visual aprobada: azul marino, blanco y dorado/amarillo; estilo moderno, profesional, premium y responsive.

Secciones previstas: navegación, hero con CTA, tres tarjetas de servicios, beneficios, galería de trabajos, testimonios solo si son reales y autorizados, contacto y footer. Animaciones sutiles y respeto de `prefers-reduced-motion`.

## Tecnología y publicación
- React + Vite.
- Publicación inicial prevista: GitHub Pages gratis, sin dominio propio de momento.
- No añadir backend, base de datos, autenticación, carrito ni pagos sin aprobación.
- Configurar `base` de Vite según el nombre real del repositorio.
- No simular envíos de formularios ni afirmar que un mensaje fue recibido sin integración real.

## Veracidad
No inventar WhatsApp/teléfono, zona de atención, dirección, precios, horarios, certificaciones, garantías, años de experiencia, testimonios ni trabajos realizados. Usa placeholders claros durante desarrollo. No presentar fotos de stock como trabajos propios. Los datos que aparezcan en la maqueta son ilustrativos.

## Calidad y proceso
Usa componentes reutilizables, HTML semántico, diseño móvil primero, accesibilidad, SEO básico e imágenes optimizadas. Evita dependencias innecesarias y secretos en el frontend.
Sigue SDD: especificación → aclaraciones → plan → tareas → implementación → validación. El coordinador delega; planner no programa; implementer hace una tarea aprobada por vez; reviewer revisa sin editar. No publicar ni hacer push sin autorización.
